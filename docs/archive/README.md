# Archive

Development notes from when Cascade was built by three parallel tracks (A: execution engine,
B: intelligence layer, C: platform), kept for history. They describe the code as it was at each
hand-off and are **not** maintained.

`BUSINESS_BRIEF.md` and `COMPETITIVE_LANDSCAPE.md` describe an early plan for a paid hosted tier
("CascadeCloud") with metered billing. That plan was dropped: Cascade is an MIT-licensed open-source
project, and the hosted tier became the self-hosted Cascade server (`gateway/`). For current status,
see [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md).
